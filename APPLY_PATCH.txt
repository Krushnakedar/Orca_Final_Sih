ORCA Feature Patch — Currents, Swell, Marine Heat Wave, SVAS
=============================================================

HOW TO APPLY
------------
1. Download orca_features_patch.zip
2. Unzip it. Paths inside are relative to project root, e.g.:
   new/Orca_Final_Sih/backend/src/...
3. Copy the files into your local Orca_Final_Sih project,
   preserving the same folder structure under backend/ and frontend/.

   Example (from the folder that contains Orca_Final_Sih):

   unzip orca_features_patch.zip
   cp -R new/Orca_Final_Sih/backend/src/*  ./Orca_Final_Sih/backend/src/
   cp -R new/Orca_Final_Sih/frontend/src/* ./Orca_Final_Sih/frontend/src/

   Or merge file-by-file if you already changed some of these files.
